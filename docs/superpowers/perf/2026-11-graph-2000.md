# 2,000 节点图谱性能手测（2026-11-27）

截图：[2026-11-graph-2000.png](2026-11-graph-2000.png)（L1，`#node=wiki/topics/t1&z=1`，1440×900）。

## 方法

- 数据：`npm run build`（真实内容）之后，`npx tsx scripts/perf-2000.ts write` 用 `buildGraph(synthIndex(2000), {})` 覆盖 `dist/data/graph.json`：2,000 节点、3,690 条边，原始 681,373 B，**gzip 58,688 B（57.3 KB）**。
- 服务：`ASTRO_PREVIEW_BACKGROUND=1 npx astro preview --port 4321`。
- 浏览器：Playwright 1.65.1 自带 Chromium，有界面窗口，1440×900，devicePixelRatio 2。第一轮不节流，第二轮用 CDP `Emulation.setCPUThrottlingRate` 4×。机器：Apple M5，10 核，16 GB，60 Hz 显示器。
- 首屏可交互：导航开始到 `#graph-app` 出现 `data-ready`（MutationObserver 记 `performance.now()`），每轮 5 次冷加载（新 context）。
- 帧率：页面就绪 1 s 后注入 requestAnimationFrame 记录器，按顺序执行 6 段、每段约 1.7 s：平移 L0 → 滚轮缩放 L0→L1 → 平移 L1 → 缩放 L1→L2 → 平移 L2 → 缩放 L2→L0。平移是按住鼠标画圆；缩放是闭环滚轮（按 `graphDebug.screenOf` 实测比例 k 补 deltaY，因为 DPR 2 下 Chromium 收到的 deltaY 减半）。各段结束时读 `data-level`，实测依次为 0,0,1,1,2,2,0，确实覆盖了三档。
- p5 fps 指第 95 百分位帧时长换算出的帧率。> 16.7 ms 的比例约 40%，大多是 rAF 时间戳在 16.67 ms 上下抖动（16.6/16.8），并不是掉帧；真正错过一次 60 Hz 垂直同步的是 > 20 ms 那一列。
- 跑了两遍，数字基本一致；下表取第二遍。

## 结果

| 指标 | 不节流 | CPU 4× 节流 | 预算 |
|---|---|---|---|
| 首屏可交互（5 次中位数） | 132 ms（126–145） | 199 ms（196–206） | ≤ 1,500 ms ✅ |
| 平移 + 缩放 中位 fps | 59.9 | 59.9 | 60 |
| 平移 + 缩放 p5 fps | 54.3 | 30.1 | — |
| 帧 > 16.7 ms | 39.6% | 50.8% | （受时间戳抖动影响） |
| 帧 > 20 ms | 0.2% | 7.1% | — |
| 帧 > 33 ms | 0.2% | 2.9% | — |
| 图谱数据 gzip | 57.3 KB | — | ≤ 150 KB ✅ |

分段（4× 节流，帧 > 20 ms / > 33 ms）：

| 段 | 中位 fps | p5 fps | > 20 ms | > 33 ms |
|---|---|---|---|---|
| 平移 L0 | 60.2 | 54.1 | 0% | 0% |
| 缩放 L0→L1 | 57.1 | 28.3 | 31.2% | 11.7% |
| 平移 L1 | 59.9 | 53.8 | 4.0% | 2.0% |
| 缩放 L1→L2 | 60.2 | 54.1 | 1.0% | 0% |
| 平移 L2 | 60.2 | 54.1 | 0% | 0% |
| 缩放 L2→L0 | 59.9 | 29.9 | 12.8% | 6.4% |

不节流时每段 > 20 ms 都不超过 1%。

## 结论

- 首屏可交互和数据体积都远低于预算。
- 不节流（这台 M5 笔记本）：平移缩放稳定在 60 fps，p5 约 54 fps，掉帧 < 1%。✅
- 4× 节流（近似中档笔记本）：平移和 L1↔L2 缩放仍是 60 fps；**穿过 L0↔L1 分界（k≈0.6，约 300 个概念标签和 1,690 个素材点淡入）的缩放会掉帧**：31% 的帧超过 20 ms，p5 约 28 fps。这一段达不到"稳定 60 fps"。⚠️
- 局限：本地 preview 没有网络延迟，真实 Pages 上的首屏时间还要加上 graph.json 的下载时间；CPU 节流只模拟 CPU，不模拟较弱的 GPU。
